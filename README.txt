PRAVEENA'S PORTFOLIO WEBSITE

Files:
- index.html: page content
- style.css: responsive design and styling
- script.js: mobile navigation and current year

HOW TO VIEW:
1. Extract the ZIP file.
2. Open the praveena_portfolio folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.

BEFORE PUBLISHING, UPDATE:
1. Replace the GitHub and LinkedIn href="#" links in index.html with your real profile URLs.
2. Replace your.email@example.com with your professional email address (in both mailto and visible text).
3. Replace project placeholder links with GitHub/demo URLs.
4. Check project descriptions, skills and achievements; edit anything that needs correction.

PUBLISHING:
You can publish this static site free using GitHub Pages. Create a GitHub repository, upload these files, then enable Pages in the repository's Settings > Pages.
