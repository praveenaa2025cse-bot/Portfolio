PRAVEENA A - PORTFOLIO WEBSITE

FILES:
- index.html: portfolio content and sections
- style.css: responsive light theme and layout
- script.js: mobile navigation and current year

VIEW LOCALLY:
Open index.html in a browser, or open this folder in VS Code and use Live Server.

CONTENT:
The education, skills, projects, achievements, certifications and coding-practice
counts are based on the supplied resume. The displayed CGPA is 8.5/10 through
the second semester. Update it when newer results are available.

CONTACT AND LINKS:
The phone number and GitHub profile are set from the supplied information.
Add a professional email address and LinkedIn URL in index.html if you want
them displayed.

PUBLISH WITH GITHUB PAGES:
The site is a static website. In the GitHub repository, open Settings > Pages
and select the main branch and root folder as the publishing source.
